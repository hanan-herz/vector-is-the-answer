# Research directions

This directory contains exploratory research memos that extend beyond the
scope of the current single-head and multi-head studies.

## Contents

- `latent-computation.md` — using frozen causal-language-model residuals as
  memory for recurrent latent computation and direct structured outputs beyond
  classification.
- `recurrence-demo-plan.md` — minimum pointer-chasing smoke test, matched
  baselines, staged experiments, and GPU measurement requirements.
- `frozen-llm-recurrence-feasibility.md` — likelihood assessment, failure-mode
  analysis, prior art, novelty constraints, and the cheapest decisive test for
  an external recurrent module over frozen token residuals.
